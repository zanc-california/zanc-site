# Community photography derivatives

These WebP files are resized, compressed copies of photographs already in the site's public gallery. No people, scenes, or event details were generated or altered. Originals are retained under `../gallery/`.

| Derivative stem | Original |
| --- | --- |
| gathering | community-friends-gathering.JPG |
| roadshow-music | zambia-us-roadshow-2025-124.jpg |
| roadshow-community | roadshow-ambassador-community-group-image.JPG |
| womens-tea | womens-tea-party-2025.jpg |

Images were EXIF-oriented, converted to RGB and resized with Pillow LANCZOS, preserving their aspect ratio; WebP quality 84, method 6. The 640 and 1280 suffixes describe maximum width. The music original is only 1000px wide and is not enlarged (its srcset descriptor is 1000w).

Homepage photographs use a stable 4:3 frame and individual CSS focal positions, without zoom animation or text covering faces. Captions identify the 2025 roadshow and tea-party photographs as past moments. The archived roadshow website was checked; its gala section uses a placeholder, so the existing ZANC gallery supplies the event photographs.
